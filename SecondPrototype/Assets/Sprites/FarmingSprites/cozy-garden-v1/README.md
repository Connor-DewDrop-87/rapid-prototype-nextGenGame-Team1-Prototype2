# Cozy Garden — 32×32 tiles and sprites (v3)

A focused first-edition, code-drawn top-down pixel-art starter pack with **127 individual 32×32 RGBA PNG sprites**. The sprites use 36 opaque palette swatches plus transparency; alpha is fully transparent or fully opaque. Art pixels are drawn on an integer grid without antialiasing. Light falls from the upper-left and shade from the lower-right.

## Sprite counts

- **64 ground and autotile sprites:** six grass arrangements, soil and planter tiles, four stepping-stone variants, and 16-way path, water-shore, and fence families, including open and closed gates.
- **6 trees and structure pieces:** two fruit trees and four aligned greenhouse pieces for a 2×2 footprint.
- **24 flowers:** four species, two colourways per species, and three growth stages.
- **20 crops and harvests:** four crops, four growth stages and one harvested item per crop.
- **13 props and critters:** ten garden props and three small animals or insects.

## Files

- assets/tiles/, assets/flowers/, assets/crops/, assets/structures/, assets/trees/, assets/props/, and assets/critters/ contain the individual sprites.
- assets/tileset-sheet.png is the 320×416 native atlas, arranged as 10 columns by 13 rows. assets/tileset-sheet-map.json maps sprite names to atlas cells and records pivots and suggested collision footprints.
- assets/demo-scene.png is a 960×960 sample garden: a 10×10 layout rendered at 3× with nearest-neighbour scaling. assets/demo-scene-map.json records its cells, layers, and object placements.
- assets/tile-repeat-test.png is a 768×768, 8×8 repeat preview alternating the six grass arrangements at 3×.
- assets/preview-contact-sheet.png is a labelled 1320×4728 overview of all sprites.
- assets/palette.png is a 736×616 palette reference. assets/palette.gpl and assets/palette.json provide the same 36 opaque swatches plus transparency.
- source/generate_pack.py is the deterministic Python generator and audit. source/requirements.txt lists its Pillow dependency.

## Tilemaps and engine setup

All source sprites are 32×32 pixels. Files in the path, water-shore, and fence autotile families with an auto_NN suffix use a four-way bitmask: N=1, E=2, S=4, W=8; NN is the sum of connected cardinal neighbours from 00 through 15. Path and water tiles include the grass base; fence tiles have transparent backgrounds. For diagonal water corners, use the provided pixel chamfers and cardinal map convention.

For **Godot**, set filtering to Nearest and use a 32×32 TileSet atlas region. Add collision shapes to fence cells and the greenhouse footprint as needed; the JSON manifest includes suggested collision and pivot notes. Place transparent plants and props above the ground and use bottom-centre pivots for upright objects.

For **Unity**, import individual PNGs as Sprites with Pixels Per Unit 32, Filter Mode Point, Compression None, and alpha transparency enabled. For the atlas choose Sprite Mode Multiple and slice on 32×32 cells; use the JSON map to identify cells. Ground sprites use a centred pivot; plants, props, trees and critters are intended to sit on a tile with a bottom-centre pivot. Keep atlas padding at zero or one pixel with no rotation. These are setup notes; no engine compatibility test is claimed.

## Rebuild and checks

Requires Python 3 and Pillow. Install the sole generator dependency, then run from this directory:

    python3 -m pip install -r source/requirements.txt
    python3 source/generate_pack.py
    python3 source/generate_pack.py --check

The generator checks sprite dimensions and alpha, shared palette colours, all three 00–15 autotile mask families, path connectivity and edge reach, fence connectivity and enclosed alpha holes, gate openings, water detail layouts, grass variants and repeat preview, atlas coordinates, and the 10×10 demo. The current v3 export audit reports 127 sprites, 37 colours including transparency, a 32px source grid, a 10×10 demo, and a valid 8×8 grass repeat preview.
